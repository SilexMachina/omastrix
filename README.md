# OmaStrix

Omarchy plugin for local models on Strix Halo. Install id: `silexmachina.omastrix`.

This repository is private. There is no release, and `omarchy plugin add` is not ready.

Cut 0.1 is a host probe and a GTT pill. It does not download a model and it does not replace `silentd.local-models`. The spec is [DESIGN.md](DESIGN.md). An agent on the machine should read [AGENTS.md](AGENTS.md).

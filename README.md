# OmaStrix

Omarchy plugin for local models on Strix Halo. Install id: `silexmachina.omastrix`.

The panel is the command center: strix-llama.cpp, GTT, Open WebUI, and a curated model table. Library root is `~/models`. Download does not load.

This repository is private. There is no release, and `omarchy plugin add` is not ready.

The spec is [DESIGN.md](DESIGN.md). An agent working on this plugin reads [AGENTS.md](AGENTS.md) before changing the machine. Live state is `bin/omastrix snapshot`, not a guess from these files.
